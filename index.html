DO SENSOR AO PAINEL

Conectar é o próximo passo.

  1. Abra o guia e prepare o código no MakeCode.
  2. Use um cabo USB com transferência de dados.
  3. Abra este painel no Chrome ou Edge em uma aba própria e clique em “Conectar Micro:bit”.
  4. Escolha a porta serial do Micro:bit.
Abrir guia e código do Micro:bit ↗

O painel precisa ficar aberto para coletar dados e controlar o LED. Sem leituras por 10 segundos, ele indica perda de sinal. O código de exemplo apaga o LED se os comandos pararem.

Histórico salvo apenas neste navegador, por até 90 dias e 100 mil leituras. Exporte o CSV para guardar uma cópia. Não há monitoramento com o navegador fechado.
